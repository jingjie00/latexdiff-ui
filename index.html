Quick tutorial

  1. In your LaTeX project you usually have two versions of the same file — often both named main.tex (old draft vs revised copy in another folder or backup).
  2. Copy the old source into the Old column (paste, or drop the .tex file).
  3. Copy the new source into the New column.
  4. Click Generate. The marked-up result appears in Tracked Changes.
  5. Copy or download the output (shown as diff.tex), save it in the same directory as your project’s other .tex files and figures.
  6. Compile diff.tex with your usual tool — e.g. pdflatex diff.tex or your editor’s build command on that file.

Do not compile main.tex expecting to see the diff markup — that file is unchanged. Only diff.tex (or whatever name you saved) contains \DIFadd / \DIFdel tracked changes.

About

Diff engine powered by latexdiff (F. Tilmann, GPL-3.0) — compares two LaTeX files and marks up changes with \DIFadd / \DIFdel.

Runs entirely in your browser via wasm-latex-tools and WebPerl — nothing is uploaded.

Developed by Tan Jing Jie (jingjietan.com). For this app’s source code, issues, and updates, visit GitHub.
